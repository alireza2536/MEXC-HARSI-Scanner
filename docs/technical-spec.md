# مشخصات فنی

## دامنه پروژه

این پروژه فقط برای داده‌های MEXC USDT Futures و HARSI در تایم‌فریم 15 دقیقه است. ارتباطی با Futures-scan-A یا CCI1000 ندارد.

## دریافت بازار

- فهرست قراردادها از endpoint عمومی اطلاعات قرارداد MEXC دریافت می‌شود.
- فقط قراردادهای فعال با `quoteCoin = USDT` و نوع perpetual در مجموعه اسکن قرار می‌گیرند.
- قیمت بازار هر قرارداد باید پیش از انتخاب نماد بررسی شود؛ شرط قیمت: کمتر از 30 USDT.
- کندل‌ها از `GET /api/v1/contract/kline/{symbol}?interval=Min15&start=...&end=...` دریافت می‌شوند.
- timestampهای API بر حسب ثانیه هستند.
- هر درخواست حداکثر 2000 رکورد برمی‌گرداند؛ تاریخچه سه‌روزه 15 دقیقه‌ای برای هر نماد 288 کندل است.

## کندل بسته‌شده

کندل 15 دقیقه‌ای فقط پس از پایان بازه زمانی‌اش مجاز به محاسبه و ارزیابی است. کندل جاری/درحال‌تشکیل نباید در شرط اسکن استفاده شود. زمان بسته‌شدن از open time به‌علاوه 15 دقیقه محاسبه و با زمان سرور کنترل می‌شود.

## تنظیمات HARSI بازیابی‌شده

- RSI Length: 7
- RSI Source: OHLC4
- HARSI Length: 200
- Open Smoothing: 1
- خروجی موردنیاز: HA_Close
- شرط: HA_Close > 5.5

## الزام تطبیق با Pine Script

صفحه TradingView مربوط به اسکریپت Heikin Ashi RSI Oscillator می‌گوید اندیکاتور realtime است و برای استفاده از مقادیر بسته‌شده باید از history offset یک یا اجرای شرط در once-per-bar-close استفاده شود. پیاده‌سازی سرور باید فقط کندل بسته‌شده را مصرف کند.

با این حال، برای برابری عددی با اسکریپت کاربر، متن کامل Pine Script باید مبنای آزمون باشد. تا وقتی فرمول دقیق RSI Open/High/Low و بازگشت HA_Open/Open Smoothing تأیید نشده، موتور محاسبه نباید فعال یا خروجی حدسی را ذخیره کند.

## ذخیره‌سازی و نگهداری

- یک ردیف یکتا برای هر نماد و زمان شروع کندل.
- OHLCV اصلی همراه با خروجی‌های محاسبه‌شده نگهداری شود.
- داده‌ها پس از سه روز حذف شوند.
- درج/به‌روزرسانی باید idempotent باشد تا اجرای مجدد داده تکراری نسازد.
