# MEXC-HARSI-Scanner

اسکنر مستقل HARSI برای قراردادهای USDT-M Futures صرافی MEXC.

## مشخصات تأییدشده

- بازار: MEXC Futures، قراردادهای USDT
- تایم‌فریم: 15 دقیقه (MEXC interval: `Min15`)
- فیلتر نماد: قیمت کمتر از 30 USDT
- نگهداری تاریخچه: 3 روز
- محاسبه و ارزیابی فقط روی آخرین کندل کاملاً بسته‌شده
- شرط اسکن: `HA_Close > 5.5`
- تنظیمات بازیابی‌شده از گفت‌وگوی قبلی: RSI Length = 7، RSI Source = OHLC4، HARSI Length = 200، Open Smoothing = 1

## معماری اولیه

1. دریافت فهرست قراردادهای فعال USDT از MEXC.
2. انتخاب قراردادهایی که قیمتشان زیر 30 USDT است.
3. دریافت کندل‌های 15 دقیقه‌ای و ذخیره OHLCV.
4. محاسبه HARSI در Worker، پس از بسته‌شدن کندل.
5. ثبت HA_Close و نتیجه شرط اسکن در دیتابیس.
6. حذف خودکار رکوردهای قدیمی‌تر از 3 روز.

## نکته مهم درباره صحت محاسبه

این مخزن عمداً از پروژه CCI1000 جداست و هیچ منطق CCI در آن وجود ندارد. قبل از فعال‌کردن محاسبه HARSI، فرمول کامل Pine Script اصلی باید با پیاده‌سازی تطبیق داده شود؛ به‌ویژه فرمول RSI کندل‌های Open/High/Low و روش دقیق Open Smoothing. تا آن زمان، هیچ مقدار HARSI حدسی نباید به‌عنوان خروجی معتبر ذخیره شود.
